# Agent notes — decode.github.io

Single-page static site (`index.html` + `assets/style.css` + `assets/images/`). No build step,
no framework — edit HTML/CSS directly, nothing to compile.

## Where affiliation/role data lives (keep these in sync)
Person/institution info is duplicated in several places; a change to someone's affiliation or
an institution being dropped/added must be applied in all of them:
- JSON-LD `member[].affiliation` in the `<head>` script (structured data for search engines).
- `<meta name="keywords">` list.
- Team section (`#team`): each person's `.team-brick .brick-detail` line, plus any
  `.team-brick--open` positions grouped under that person's research area.
- Partners section (`#partners`): `.partner-grid` tiles (`.partner-grid` CSS grid column count
  must match the number of tiles — e.g. `repeat(3,1fr)` for 3, `repeat(2,1fr)` for 2) and the
  `.cooperation-list`.
- Footer `.footer-hub` sentence summarizing which institutions run the project.

## External paper/DOI lookups
`dl.acm.org` (and likely other publisher sites behind Cloudflare) return 403 to both `curl` and
the `WebFetch` tool — no direct scraping. Use the Crossref API instead, which is open and
reliable: `curl -s "https://api.crossref.org/works/<DOI>"` returns JSON with title, authors,
affiliations, abstract, venue, license/open-access status, volume/issue/pages.

No headless browser or SVG/PDF rasterizer is available in this environment (no
rsvg-convert/inkscape/cairosvg/chromium). When asked for "a screenshot of the paper", a real
screenshot isn't achievable — instead build a stylized SVG "paper preview card" (see
`assets/images/visual-privacy-paper.svg`) using real metadata pulled from Crossref, styled with
the site's own palette (`--accent`/`--accent-2` from `assets/style.css`), and link it to the
DOI/paper URL. Say plainly that it's a generated preview, not an actual screenshot, if asked.
